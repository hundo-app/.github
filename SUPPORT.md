# Getting help

- **A question, a tip, an idea to discuss**: [Discussions](https://github.com/hundo-app/releases/discussions)
- **A bug in the app**: [report it](https://github.com/hundo-app/releases/issues/new?template=bug.yml), best from the app (**Improve Hundo → Report a bug**)
- **A wrong item, name or place in a game**: [report it](https://github.com/hundo-app/modules/issues/new?template=data.yml), or **Report** on the item in the app
- **A game Hundo should read**: [share a save](https://github.com/hundo-app/releases/issues/new?template=save.yml)
